# Paperless
Epub reader

Very simple epub reader using only the Gtk4 toolkit.

Requires:
- python3
- gtk4 (and Adwaita)

Features:
- very lite, use the textview widget (but it has very basic);
- basic settings: foreground and background colours; font type and size; space between lines of text;
- table of contents;
- pictures.

Support the epub v. 3 and v. 2, but some epubs might not be loaded properly (mainly/only the TOC).
